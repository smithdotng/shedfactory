# Shedfactory Digital Creative Agency

Shedfactory is a digital creative agency website built with Node.js, Express, and EJS.

## Features

- Dynamic pages using EJS templates
- Contact form with storage in JSON files
- Newsletter signup with AJAX
- Admin panel to view subscribers and contact messages (basic auth protected)

## Prerequisites

- Node.js (v14 or higher)
- npm
